## 🌐 Overview

A fully custom, hand-built portfolio — zero templates, zero page builders. Designed around a **"Neural Systems"** visual language: dark navy backdrops, glassmorphism panels, and a **live 3D neural network** that boots up from raw chaos into organized structure right on load.

Every interaction is intentional — a terminal-style boot sequence, a cinematic curtain reveal, scroll-linked storytelling, and a hidden easter egg for the curious.

> *This isn't a portfolio template with content swapped in. Every animation, timeline, and visual system was designed and built from scratch.*

## 🛠️ Tech Stack

<div align="center">

| Layer | Technologies |
|:---:|:---|
| **Structure** | HTML5 — Semantic, accessible markup |
| **Styling** | CSS3 — Custom properties, glassmorphism, responsive grid + Bootstrap 5 |
| **Logic** | Vanilla JavaScript (ES6+) — no framework overhead |
| **Animation Engine** | GSAP + ScrollTrigger — timeline-based, scroll-linked, replay-aware |
| **3D Rendering** | Three.js — custom layered neural network visualization |
| **Forms** | Formspree — serverless AJAX submission |
| **Icons** | Font Awesome 6 |

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/D0027/my-portfolio.git

# Navigate into the project
cd my-portfolio

# Serve locally (or just open index.html directly)
npx serve .
```

Deployed via **GitHub Pages** — push to `main`, enable Pages under repo Settings, done.
